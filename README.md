# 2-Achsen-Matrix

Web-App (geplant) zum Arbeiten mit den gängigsten **2-Achsen-Methoden**: Eisenhower-Matrix, Wert/Aufwand, Macht/Interesse (Stakeholder), Risikomatrix und Stacey-Matrix – dazu eigene Matrizen mit frei wählbaren Achsen.

Technisch und gestalterisch angelehnt an die Schwester-Apps [Morphologische Matrix](https://github.com/method-commons/morphological-matrix-app), [User Stories](https://github.com/method-commons/user-story-app) und [5 Warum](https://github.com/method-commons/5-why-app).

## Stand

Bisher gibt es nur **Mockups** (statische Entwürfe): [docs/mockups/](docs/mockups/) – Übersicht, Methodenwahl, je eine Ansicht pro Methode, Bericht, Anpassen-Dialog und mobile Ansicht.
